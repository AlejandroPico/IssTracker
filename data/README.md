# Carpeta de datos

Esta versión no incluye datasets pesados dentro del repositorio. Las fronteras se cargan desde el GeoJSON público usado por Globe.gl y la trayectoria NASA OEM se consulta desde el endpoint público de NASA cuando el navegador lo permite.

En una versión futura se puede copiar aquí una versión local de `countries.geojson` para reducir la dependencia de GitHub Raw.
